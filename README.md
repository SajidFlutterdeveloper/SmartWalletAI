# SmartWalletAI
> **Intelligent Financial Management with AI-Powered Insights**

SmartWalletAI is a modern Android application designed to help users track their expenses, manage budgets, and gain financial clarity through intelligent parsing and data visualization. Developed as a final year university project, it integrates cutting-edge technologies like Firebase, Biometrics, and ML Kit.

---

## Project Overview
The **SmartWalletAI** project addresses the common challenge of personal finance management. Unlike traditional ledger apps, it provides a secure, automated, and intuitive experience. It features enterprise-grade security via biometrics, real-time cloud synchronization, and smart receipt scanning capabilities.

## Main Features
*   **Secure Authentication:** Firebase-powered Login/Signup with an additional layer of **Biometric Security**.
*   **AI Expense Parsing:** Leverages Google ML Kit for text recognition to scan receipts and automate entry.
*   **Data Visualization:** Interactive charts and graphs using **MPAndroidChart** to visualize spending patterns.
*   **Real-time Sync:** Powered by **Firebase Firestore** to keep data consistent across devices.
*   **Smart Reminders:** Daily notification triggers (9 PM) to ensure users never miss logging a transaction.
*   **Profile Management:** Customizable user profiles with cloud-hosted profile pictures.
*   **Smooth UX:** Modern UI with smooth fragment transitions, haptic feedback, and Material Design 3.

## Technologies Used
*   **Language:** Java + Kotlin
*   **Architecture:** MVVM (Model-View-ViewModel)
*   **Database:** Room (Local) & Firebase Firestore (Cloud)
*   **Security:** Android Biometric API, Firebase Auth
*   **AI/ML:** Google ML Kit (Text Recognition)
*   **Navigation:** Jetpack Navigation Component
*   **Charts:** MPAndroidChart
*   **Image Loading:** Glide
